## 验收边界

本机缺少 Chromium，且 GitHub 连接器未下载大于1MB的入口照片，因此本机浏览器测试及含该照片的完整资源检查不能证明通过。原照片在上游，未修改或删除。PR CI 使用完整 checkout，执行原有检查、新增数据流测试及实际四语预约页浏览器测试，并生成手机截图供审阅。

浏览器测试使用本地服务器并阻止外部网络，不给店铺发送邮件、不写真实预约台账、不产生生产 GA4 流量。代码测试不能证明已部署的 Google Apps Script 与仓库一致。
