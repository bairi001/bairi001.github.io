# Google Apps Script 网页预约隐私说明草案

> 本文是内部确认草案，不是当前公开隐私政策。网页 POST 仍未启用，不应把此草案直接当作已经生效的声明。

正式启用前需由负责人确认并形成可公开文案：

1. **收集项目**：姓名、电子邮箱、电话号码（选填）、希望日期与时间、人数、所选套餐、备注、语言、来源参数以及技术性防重复标识。
2. **利用目的**：处理预约申请、确认空位、联系客人、维护预约台账、防止滥用和排查提交故障。
3. **使用的 Google 服务**：Google Apps Script 接收提交，Google Sheets 保存预约台账，Gmail 向店铺发送通知。
4. **账号访问权限**：明确哪些人员和账号可访问脚本、表格与通知邮箱，以及人员变更时的权限回收流程。
5. **数据保存期限**：由经营负责人根据实际业务、会计、纠纷处理和法律要求确定；本草案不预设期限。
6. **删除规则**：明确到期删除、客人请求处理、备份和误删恢复规则。
7. **数据处理与委托安排**：确认 Google 服务的使用方式、合同关系、管理责任和必要的安全措施。
8. **境外处理**：基于实际 Google 账号、服务设置和适用条款确认是否涉及境外处理；本草案不作预先断言。
9. **联系窗口**：

   凱鴻商事株式会社<br>
   身悠晏

10. **法律确认**：正式开放前由合适的专业人士或负责人完成日本个人信息保护法及相关规则的最终确认。

网页 POST 真正启用时，预约表单还必须显示正式隐私政策链接和明确的同意确认。
